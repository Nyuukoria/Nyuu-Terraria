# v0.5.0 validation

Built against the installed tModLoader 1.4.5-dev build `25921d5f` (.NET 10). Production compilation finished with **0 errors and 0 warnings**. Dedicated-server regression fixtures completed **461 assertions** covering content/assets, quests, spellcraft, Worldbound state and travel, reactions, talents, encounters, crafting, animated frame registration, backpack navigation, Escape handling and the buff layout hook.

The showcase exporter verified all **145 mod items**, 44 vanilla ingredients, nine catalog chests and six separate destinations. Its player file was reloaded successfully, including saved health/mana upgrades, spell mastery and inventory. The showcase player and world also loaded in the normal graphical client. Requests, talents, profile, wildlife, dialogue and spellbook panels received visual checks in the isolated client during development.

The visual pass rebuilt creature sheets, refreshed town characters and garment icons, fitted worn outfit sheets, and aligned the new furnishings to their placement footprints. Frontier and Reverie PNG audits found nonempty images with binary transparency. Animated sprites are cropped to a single frame for documentation previews.

The final ordinary-client keyboard shortcut check could not be confirmed through the desktop input tool: synthetic key presses were not observed in gameplay. Saved bindings were inspected and the programmatic Escape/navigation checks passed. Physical-key input, every combat encounter, all outfit poses, every screen scale, interactions with unrelated mods and a real multiplayer session still need broader playtesting. Passing checks does not establish perfect balance or compatibility with future development builds.

Test fixtures are published separately under `tests/`; they are excluded from the playable `.tmod` and source ZIP.
