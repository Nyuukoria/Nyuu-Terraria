# v0.5.2 validation

[Home](../../README.md) · [Release notes](../releases/v0.5.2.md)

The isolated dedicated-server run passes **596 automated assertions**. This includes the previous content, spellcraft, backpack, quest reward, equipment routing and world checks, plus complete animation registration coverage, valid sprite-part rectangles, finite transforms and distinct idle/moving/action poses for all ten animation profiles.

Production and fixture builds compile with **zero errors and zero warnings**. The fresh showcase exporter verifies all six destination rectangles have the new 96-horizontal / 16-vertical tile buffer, exports 145 mod items into nine catalog chests with 44 vanilla ingredients, and reloads the character file to check its data. Fixture code is excluded from the playable mod and source ZIP.

The first wider-spacing attempt exposed a sixth-destination placement failure. The revised search examines denser horizontal candidates and additional rows, while still rejecting all occupied tiles, walls and liquid. Existing generated areas remain untouched. Animation body partitions and alpha bounds are cached rather than rebuilt for every draw.

These checks validate registration, animation data, world generation and saved data. This pass does **not** establish a full graphical review of every animation pose or multiplayer combat; those remain playtesting limits. The previous release's graphical backpack and quest-claim checks are recorded in [v0.5.1 validation](0.5.1.md).
