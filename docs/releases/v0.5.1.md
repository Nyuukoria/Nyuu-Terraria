# v0.5.1 — Repair pass

Fixed the backpack's slot-41 drawing exception, cursor-driven Equipment page switching, direct request claims, UI click handling, and quest hand-ins from backpack storage. Completed quests cannot be claimed twice.

Retained the established artwork. Corrected NPC facing and floor alignment, grounded enemies and the Dew Fox pet, aligned furniture to the floor, restored animated trouser legs and fitted skirt hems, and stopped a single-frame boomerang from using pet animation indices.

Rebuilt all six newly created pocket landscapes with varied terrain, gardens, pools, ruins and shelves, shorter fighting ledges and connected starglass islands. Forests now use Terraria's native tree framing instead of tile-built canopies, and forest/garden scaffold ledges are removed. Existing generated areas are preserved. A new **Nyuu Showcase 051** provides the updated scenery separately.

Reworked GitHub navigation into a compact player hub, complete linked guide, recipe reference, release pages, test report and collapsible roadmap.
